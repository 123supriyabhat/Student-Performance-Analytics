# 📊 Student Performance Analytics Dashboard

## About the Project
This project is an interactive Student Performance Analytics Dashboard developed using Python and Streamlit.

It helps analyze student marks, compare subject-wise performance, identify top-performing students, and generate academic insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## Features
- Student performance analysis
- Subject-wise average marks
- Individual student performance
- Top 5 performing students
- Class average calculation
- Pass percentage calculation
- Student result distribution
- Interactive dashboard filters
- CSV report download
- Data cleaning and analysis

## Dataset
The project uses a sample dataset containing student marks in:
- Maths
- Science
- English
- Computer

## How to Run

1. Clone this repository.
2. Install the required libraries:

   pip install pandas numpy matplotlib seaborn streamlit

3. Run the dashboard:

   python -m streamlit run dashboard.py
